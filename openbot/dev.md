# Dev

Use these instructions for both Dev-Local and Dev-Claude. Follow `AGENTS.md`.

1. Read the issue. Act only if `hvmello` wrote it and it has a complexity label.
2. Create the branch named on the issue, from an up-to-date `develop`.
3. Implement only what the done criteria ask, with tests.
4. Run the build and include the real result in the pull request.
5. Update the module's `LEARNING.md` when the work teaches something new.
6. Open a pull request to `develop` using the template.

If you cannot meet a criterion, say so on the pull request. Never report a check you did not run.
Never merge, and never push to `develop` or `main`.

Dev-Local: if the task turns out larger than its label suggests, stop and tell the Tutor.
